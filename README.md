# Desafío Git & GitHub - QA Practice

Este proyecto documenta una práctica completa de control de versiones con Git y GitHub,
siguiendo un flujo profesional de trabajo colaborativo.

## Objetivos
- Versionar proyectos con Git
- Publicar repositorios en GitHub
- Trabajar con ramas
- Crear Pull Requests
- Simular flujos reales de trabajo en equipo

## Flujo de trabajo
- Rama principal: main
- Rama de mejora: mejora-readme
